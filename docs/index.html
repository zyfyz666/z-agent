带观察者的桌面编程 Agent

让长程任务保持方向。

Z 将对话、工具执行、项目修改和审阅放在同一个工作台。观察者结合原始目标、近期行动和验证记录，帮助模型在长时间、多步骤的任务中保持全局视野。

开始使用 了解功能

观察者，让判断有迹可循

为观察者单独选择模型、思考强度和检查频率，与主 Agent 的模型配置相互独立。

  • 确认偏离才提醒。模型观察默认继续观察，只有明确确认主 Agent 进入误区、且有可核验的证据时，才发出纠偏提示。
  • 不介入也留记录。每次完成的模型判断都会留下时间和理由；无需介入时明确显示「判断为不介入」。
  • 历史跟随对话。切换对话或重新打开应用后，可以查看已保存的观察记录。
