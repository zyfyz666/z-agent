# Z

Z 是一个面向长程任务的桌面编程 Agent，将对话、项目操作、工具执行和代码审查放在同一个界面中。内置的 **「观察者」** 结合任务目标、工具行为和验证记录，为执行中的 Agent 提供纠偏提醒，帮助模型在长时间、多步骤的工作中保持全局视野。

## 观察者：帮助模型保持长程任务的全局视野

长程任务往往包含多轮探索、修改和验证。随着执行步骤增加，模型可能困在某个局部问题里：反复查看相同内容、沿用缺少进展的方案，或者继续依赖修改前的测试结果。

**观察者的核心价值，是帮助模型提高长程任务中的全局视野。** 它把近期行动放回原始目标和已有执行证据中检查，在出现停滞信号时提醒模型重新审视方向、调整策略，并保留已经验证的成果，让后续工作继续围绕整体任务推进。

观察者关注以下几类信号：

- **目标偏移**：近期行动反复重复、又缺少与原始目标的关联时，提示模型重述目标，核对当前工作是否仍在服务于它。
- **重复与信息停滞**：识别重复操作，以及持续围绕已探索内容打转、缺少新信息的情况，减少无效尝试。
- **策略固化**：当方案变化很小、进展又长期不足时，提醒模型改变策略，或给出继续当前路线的依据。
- **验证过期**：发现通过检查后又修改了代码，提示重新验证，避免把旧的成功结果当作当前状态。

这些提醒会直接送入正在执行的 Agent，作用于后续工作。随着停滞持续，提醒可以升级为更明确的策略调整要求；提示也会要求保留已经验证的工作，避免没有具体理由地重复执行。

**执行过程可见。** 观察者面板默认展开，展示当前任务的运行状态、触发原因、提醒投递情况和事件历史。你可以手动关闭或从侧栏重新打开；任务更新或切换会话不会强制打开已经关闭的面板。面板使用真实运行事件。

**记录跟随对话。** 打开一个对话，观察者会恢复该对话的记录；在面板的「观察记录」中可以选择具体轮次，较早的轮次可按需加载。查看历史时，后台任务不会覆盖所选记录。已保存的记录在重启后仍可查看；每轮保留检查计数、最近的模型判断和最近 30 条提醒。没有保存观察者数据的旧轮次会明确显示「此轮没有监控记录」。

**两种观察方式。** 默认使用确定性规则，无需调用模型。也可以在输入框下方点击「观察者」，为它单独选择 API 和模型，与主 Agent 的连接互不影响。模型只接收任务目标和近期行动摘要，在后台补充判断，不执行工具；模型不可用时，规则观察继续工作。模型观察会产生所选服务的调用费用。

**细节模式。** 在观察者设置中展开「细节模式」，可设置每新增 **1–100 个工具动作**检查一次，默认 **6**。这里的动作指读文件、执行命令等工具操作，不是聊天消息；规则首次判断至少需要 6 个动作。模型判断期间不会重复发起请求，主任务结束后取消未完成的观察。设置从下一轮任务生效。

## 更多功能

- **项目与任务**：无需先选择工作区即可对话、生成文件和执行任务。Z 会为每个对话创建独立的持久任务文件夹；也可以选择已有项目，修改代码和查看变更。跨目录操作沿用当前权限设置，无需仅为切换目录新建对话。
- **上下文管理**：支持会话管理与上下文压缩，延续较长的任务。
- **数学公式**：回答支持 `$…$`、`$$…$$`、`\(…\)` 和 `\[…\]` 的 LaTeX 数学排版，公式与字体在本地渲染。代码块保留源码，流式文本在该段输出完成后排版。
- **模型接入**：在设置中添加模型服务，然后点击输入框右下角的模型按钮，在同一个菜单里选择供应商和模型，也可调整推理强度。每个对话独立保存主模型，切换一个对话的模型不会影响其他对话；正在执行的轮次继续使用启动时选定的模型。
- **思考强度**：档位目前是全局设置，在每轮任务启动时读取。Claude 4.7 的 Anthropic 通道会启用自适应思考并传递对应的 effort 档位。较高档位表示希望模型投入更多思考，不保证固定思考时长；执行中调整档位不会改变已启动的轮次。
- **运行中引导**：任务执行期间，输入文字后按 Enter 或点击发送，指令会送入当前任务，在后续模型步骤中生效。也可以点「排队」留到下一轮执行；含附件、技能或子代理的消息使用排队方式。
- **对话独立提问**：提问和权限确认只在所属对话中显示。后台任务会标记「待回答」或「待确认」，切回后恢复问题、已选答案和填写草稿；不同对话的请求不会互相覆盖。
- **暂停与继续**：点击停止后，保留原始消息、引导记录、已生成的回复和工具执行记录。切换对话或重启后仍可查看，再发消息可沿用原有上下文继续。
- **工具扩展**：通过技能和 MCP 接入更多工具，配合代码审查等工作流完成任务。

## 开始使用

源码运行环境：**Windows x64 或 macOS arm64，Node.js 22**。

```bash
git clone https://github.com/zyfyz666/z-agent.git
cd z-agent
npm ci
npm start
```

首次启动后：

1. 在设置中配置模型服务和访问凭据。
2. 新建任务，直接描述你希望完成的工作。
3. 文件默认保存在系统文档目录下的 `Z Agent/Tasks/<会话 ID>`；处理已有项目时，可在任务开始前选择项目文件夹。
4. 在对话中查看执行结果，通过观察者面板查看运行状态。

已有用户的模型配置、会话和历史记录会沿用现有的数据目录。

## 开发与构建

```bash
npm run dev             # 开发模式
npm test                # 单元测试
npm run build           # Windows 安装包
npm run build:portable  # Windows 便携版
npm run build:mac       # macOS arm64 镜像，需在 macOS 上构建
```

构建产物输出到 `dist/`，应用名称为 **Z**。

## 观察者高级设置

可通过环境变量调整观察者的运行规则：

| 变量 | 默认值 | 作用 |
| --- | --- | --- |
| `WD_WATCHDOG` | 开启 | 设置为 `0` 可关闭观察者的运行干预 |
| `WD_WATCHDOG_N` | `6` | 无界面配置的运行入口使用此间隔；桌面端以观察者设置为准 |
| `WD_WATCHDOG_HALT` | 关闭 | 设置为 `1` 时，持续停滞可触发结束运行的请求 |
